# Service images

Drop real photos into this folder using these exact filenames — the
Services section (`src/data/services.js`) is already wired to load them.
Recommended size: ~960×600px (16:10), .jpg or .webp, optimized/compressed.

- doorstep-scrap-collection.jpg — a scrap pickup / loading scene
- office-scrap.jpg — retired office electronics, computers, cabling
- industrial-scrap.jpg — factory/workshop machinery or metal scrap
- government-account-scrap.jpg — organized industrial/decommissioned equipment
- scrap-tender.jpg — bulk scrap lot / tender-style yard
- bank-scrap-tender.jpg — decommissioned IT/branch equipment

If a file is missing, the card automatically falls back to the existing
illustrated tile — nothing breaks, it just won't look final until the real
photo is added.

Good free, properly licensed sources if you don't have your own photography:
Unsplash (unsplash.com) and Pexels (pexels.com) both offer free-to-use,
commercially licensed images with no attribution required — search "scrap
metal", "recycling yard", "industrial machinery", "e-waste" etc. and
download the images under the filenames above.
